# models/ —— 板端模型与版本约束

当前使用 **一阶段单模型** `own_best`（4 类），一次推理同时出人框和帽/衣框。

| 文件 | 角色 | 说明 |
| --- | --- | --- |
| `own_best_i8.rknn` | **板端一阶段模型** | 4 类 `person/helmet/no_helmet/vest`，RKNN version **2**（rknn-toolkit2 1.3.0 生成） |
| `own_best_headcut.onnx` | PC 自检用 | 与 rknn 同源的 headcut ONNX，输出 `(1,64,8400)`+`(1,4,8400)`，供 `tools/pc_onnx_check.py` 在电脑上验证解码/阈值 |
| `own_best.pt` | 原始训练权重 | 参考 / 重新导出用 |
| `labels_own.txt` | 类别名 | `0 person` / `1 helmet` / `2 no_helmet` / `3 vest` |

判定逻辑：一次推理出人框 + 帽/衣框，按"装备框落在人框内的**重合率**"（默认 `>= 0.5`）关联：
同时匹配到帽+衣 = **SAFE**，只匹配到一个 = **PARTIAL**，都没匹配到 = **UNSAFE**。
`no_helmet` 按需求**不参与判定**（没戴帽的人靠"匹配不到 helmet"判出来）。
参数见 `config/safe_config.json` 的 `detect.gear_overlap` / `conf_person` / `conf_gear`。

> 原**两级方案**的模型（`yolov8n_headcut.rknn` COCO 人体 + `yolov8n_safe_headcut_i8.rknn`
> 安全帽/衣）已从本包删除。如需回看，可在 git 历史里找回（`git log -- models/`）。

## 关键约束：版本必须和板端 librknnrt 同代

本板 `librknnrt` 是 **1.3.0**（驱动 0.8.2），只能加载 **RKNN model version 2** 的模型
（由 rknn-toolkit2 **1.3.0** 生成）。用 2.x 工具链生成的模型是 version 6，上板会报：

```
E RKNN: Invalid RKNN model version 6
E rknn_init, load model failed!
```

换模型时务必核对版本：

```bash
python3 -c "import struct,sys;d=open(sys.argv[1],'rb').read(16);print('version=', struct.unpack('<I', d[8:12])[0])" models/own_best_i8.rknn
```

应为 `version= 2`。若板端 librknnrt 升到 2.3.x，需用 2.3.2 环境重转（产物是 version 6，旧板子不能再加载）。

## 怎么重建（转换脚本在 `../SafeDetect_Model_trans/`）

转换环境：`~/miniconda3/envs/rknn130`（rknn-toolkit2 1.3.0）+ `venv310`（ultralytics）。

```bash
cd ../SafeDetect_Model_trans
EXPORT_PY=/home/ljr/rockchip_rknn_yolov5/yolov5_6.2_export/venv310/bin/python
RKNN_PY=~/miniconda3/envs/rknn130/bin/python

# 1) .pt -> 完整 ONNX
$EXPORT_PY scripts/export_onnx.py --pt own_best.pt --out onnx/own_best_full.onnx --imgsz 640
# 2) 量化图清单（用模型自己的训练集图片）
python3 scripts/make_quant_dataset.py --dir ../Safe_Model_Trainning/construction-ppe/images/train \
    --out quant_images_own.txt --max 200
# 3) headcut 图手术（nc=4！脚本默认 3，必须显式覆盖）
$RKNN_PY scripts/prepare_headcut_onnx.py --onnx onnx/own_best_full.onnx \
    --out onnx/own_best_headcut.onnx --imgsz 640 --nc 4
# 4) i8 量化导出 RKNN
$RKNN_PY scripts/convert_to_rknn.py --onnx onnx/own_best_headcut.onnx \
    --rknn rknn/own_best_i8.rknn --imgsz 640 --quant i8 --dataset quant_images_own.txt

# 5) 拷贝到本目录
cp rknn/own_best_i8.rknn onnx/own_best_headcut.onnx own_best.pt models/
```

> 注意：`prepare_headcut_onnx.py` 默认 `--nc 3`，own_best 是 4 类，必须传 `--nc 4`，
> 否则 class 输出形状会错。转换脚本里的 4 个文件历史上是 GBK 编码（非 UTF-8），
> 已在本仓库修复为 UTF-8，Python 3 可直接运行。
