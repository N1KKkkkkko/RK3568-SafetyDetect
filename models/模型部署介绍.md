# models/ —— 板端模型与版本约束

| 文件 | 角色 | 类别数 | RKNN 版本 |
| --- | --- | --- | --- |
| `yolov8n_headcut.rknn` | 一级：找人体框（COCO，只取 class 0 = person） | 80 | **2** |
| `yolov8n_safe_headcut_i8.rknn` | 二级：安全帽 / 安全衣判定 | 3 | **2** |

## 关键约束：版本必须和板端 librknnrt 同代

本板 `librknnrt` 是 **1.3.0**（驱动 0.8.2），只能加载 **RKNN model version 2** 的模型
（由 rknn-toolkit2 **1.3.0** 生成）。用 2.x 工具链生成的模型是 version 6，上板会报：

```
E RKNN: Invalid RKNN model version 6
E rknn_init, load model failed!
```

> 踩坑记录：`../SafeDetect_Model_trans/rknn/yolov8n_headcut.rknn` 是早期用 2.x 工具链转的（version 6），
> 上板加载失败；本目录里的这份已用 1.3.0 重转（version 2）。
> **两个模型都要是 version 2**，换模型时务必用下面命令核对版本：1.3.0 / 换 2.x 工具链后，要用 2.3.x 重新转换并回归。
```bash
python3 -c "import struct,sys;d=open(sys.argv[1],'rb').read(16);print('version=', struct.unpack('<I', d[8:12])[0])" models/yolov8n_headcut.rknn
```

## 怎么重建

两个模型都由 `../SafeDetect_Model_trans/` 的脚本产出（转换环境：`~/miniconda3/envs/rknn130`，rknn-toolkit2 1.3.0）：

```bash
cd ../SafeDetect_Model_trans

# 二级：安全帽/安全衣（best.pt -> ONNX -> headcut -> RKNN i8）
bash run_all.sh

# 一级：COCO 人体检测（yolov8n.pt -> ONNX -> headcut --nc 80 -> RKNN i8）
bash scripts/build_person_rknn.sh
```

如果板端换了 2.3.x 的 librknnrt，则把 `RKNN_PY` 指向 2.3.x 环境重跑一遍（此时的模型是 version 6，旧板子不能再加载）。
